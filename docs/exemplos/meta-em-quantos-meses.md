## Fórmula

```text
saldo do mês = saldo anterior × (1 + i) + A
```

Com rendimento não há uma divisão simples: o saldo é simulado mês a mês, até alcançar a meta.

O aporte é feito no **fim** de cada mês, então só começa a render no mês seguinte.
